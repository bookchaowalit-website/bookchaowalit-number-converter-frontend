# Number Base Converter

Convert integers across common numeric bases.

## Features
- Binary / Octal / Decimal / Hex
- Live conversion from any field
- Copy outputs

## Limitations
- Integer only (no floating point)
- BigInt-backed for large values

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
